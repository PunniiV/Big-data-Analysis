# 🚀 CODTECH Internship - Task 1

## 🔍 Big Data Analysis using PySpark | Netflix Dataset

This project is part of the **CODTECH Data Analysis Internship**. The task focuses on performing large-scale data analysis using PySpark on the Netflix dataset.

---

### 📦 Dataset

**Netflix Titles Dataset**  
- Source: [Kaggle - Netflix Titles](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- Contains TV shows and movies available on Netflix as of 2021.
- Columns include: `title`, `type`, `country`, `date_added`, `listed_in`, etc.

---

### ⚙️ Technologies Used

- Python 🐍
- PySpark ⚡
- Jupyter Notebook 📓
- Big Data Concepts

---

### 📊 Key Insights

- **Top Countries**: USA, India, and the UK produce the most content.
- **Popular Genres**: Dramas, International Movies, and Comedies are dominant.
- **Content Growth**: Major content additions occurred after 2015.
- **Content Type**: Netflix has significantly more movies than TV shows.
